# Code of Conduct

ScoutCTX is committed to a friendly, safe, and inclusive community.

Be respectful, assume good intent, give actionable feedback, and make space for people with different backgrounds and experience levels. Harassment, discrimination, personal attacks, doxxing, and other harmful behavior are not acceptable in project spaces.

Maintainers may edit or remove contributions that violate these expectations and may temporarily or permanently restrict participation. Report conduct concerns privately to the repository maintainers through GitHub. Reports will be handled with discretion.

This code applies in all project spaces and whenever someone publicly represents the project.
